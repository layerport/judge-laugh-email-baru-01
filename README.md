## What it does

`main.py` writes one original funny one-liner to `/output/entry.txt`. The program is fully deterministic — no randomness, no timestamps, no network — so every run produces the exact same line.


## The line

> I finally organized my life into a spreadsheet, and the spreadsheet filed a complaint about working conditions.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
